# Nico's Toy Shop Implementation Plan

> **For agentic workers:** Execute inline, task by task. Preserve this checkpoint across sessions.

**Goal:** Add a bilingual, privacy-isolated physical-product storefront at `/store`, with real sales disabled until owner approval.

**Architecture:** A separately routed React store, a build-time public catalog compiler, and an adult-initiated external order-request flow. No payment processor, customer database, child-profile access, tracking, new dependencies, or paid infrastructure. Existing Cloudflare static-asset deployment and gameplay remain intact.

**Tech Stack:** Existing React/Vite/TypeScript, Vitest and Playwright; GitHub CI and Cloudflare.

## Global Constraints

Only BoneManTGRM/Nicos-Adventures is in scope. Preserve all games, artwork, browser-local saves and backup/restore, bilingual behavior, and offline play. Never fabricate products, photos, prices, stock, fulfillment, safety approvals, contact details or payment status. Public sales default off. This repository is public: do not commit private drafts, original photos or private contact details. Only deliberately approved public product data and sanitized images may be submitted for publication. Synthetic fixtures live exclusively in tests and never in public output.
